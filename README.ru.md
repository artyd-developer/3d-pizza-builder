# Pizza Builder

<img width="800" height="600" alt="review" src="https://github.com/user-attachments/assets/b0fb633d-34d5-406b-b9fe-36eb9130d4cd" />

Интерактивный конструктор пиццы из четырёх четвертей, отрисованный на чистом WebGL 2.0 и GLSL ES 3.00. React отвечает за элементы управления, а движок сцены — за рендеринг и анимацию.

## Запуск локально

Используйте актуальную версию Node.js, затем выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Команда `npm run build` создаёт production-сборку в `dist/`, а `npm run preview` запускает её локально. Команда `npm test` запускает автоматические проверки движка.

## Поддержка браузеров

Нужен современный браузер для компьютера или мобильного устройства с включённой поддержкой WebGL 2.0. При отсутствии WebGL 2.0 приложение покажет сообщение о неподдерживаемом браузере. При восстановлении графического контекста текущая пицца сохраняется.

## Управление

1. После загрузки изображений появляется случайная пицца. Нажмите **Create my bomb**, чтобы очистить её и собрать свою.
2. Выберите четверть пиццы, затем до двух из шести ингредиентов. Каждый новый ингредиент добавляет 12 кусочков. Третий ингредиент заменяет самый ранний; повторный выбор уже добавленного ингредиента ничего не меняет.
3. Карточки популярных пицц применяют свой рецепт ко всем четырём четвертям. Рецепты сохраняются, пока открыта страница.

Элементы управления являются нативными кнопками и доступны с клавиатуры. Превью ингредиентов используют те же исходные спрайты, что и пицца. Добавленные фотографии пиццы служат только визуальными референсами и не показываются на странице.

## Сборка для GitHub Pages

Конфигурация Vite использует относительные пути к ресурсам, поэтому production-сборка работает по адресу проекта GitHub Pages, например `https://<user>.github.io/<repository>/`.

```sh
npm ci
npm run build
```
